This repository includes HTML (https://mayaogonah.github.io/psychiatric-tbims/) and PDF files created with Quarto, which details the code used to estimate the association between psychiatric illness and substance use, and TBI aetiology (violent vs nonviolent injury). This script draw from the TBIMS Public Use Data Set, which can be downloaded from the TBIMS website (https://www.tbindsc.org/public/requestdata.aspx).
